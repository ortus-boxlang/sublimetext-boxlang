# BoxLang File Icons

Place your BoxLang icon PNG at:

- `icons/file_type_boxlang.png`

Notes:

- Recommended size: 16x16 and 32x32-compatible source PNG.
- The mapping is configured in `File Icons.sublime-settings`.
- Extensions mapped: `.bx`, `.bxs`, `.bxm`.

After adding/replacing the icon, restart Sublime Text or run:

- `A File Icon: Revert to a Freshly Installed State`
